# Epoch 17.6.1 Verification Report

## Scope

Portable packaging correction for the Epoch 17.6 Focused Studio release. No application source, asset, schema, or runtime dependency version was changed.

## Root cause

The initial archive contained 81 absolute tarball URLs generated by the controlled build environment's private npm mirror. External machines could not resolve that host and reported `ETIMEDOUT`.

## Corrective action

- Replaced the 81 private-mirror URLs with `https://registry.npmjs.org/` equivalents.
- Preserved package versions and Subresource Integrity hashes.
- Added `npm run lock:portable`, which fails release audits if a private registry reference is present in `package-lock.json`.
